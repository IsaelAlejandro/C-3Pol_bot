# C-3Pol_bot
C-3Pol_bot is a MATLAB-based toolkit designed for the generation of synthetic Dipole Spread Function (DSF) data for high-numerical-aperture (high-NA) imaging systems and for the estimation of dipole orientation and polarization parameters.

# Requirements
MATLAB (All codes were tested using MATLAB R2024b)

Image Processing Toolbox

Parallel Computing Toolbox
